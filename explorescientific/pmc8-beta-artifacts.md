# PMC-Eight INDI Beta Artifacts

This repository can produce beta binary artifacts for the Explore Scientific PMC-Eight INDI server/driver.

The artifacts are release downloads. They are not committed to the repository.

Formal beta release:

```text
https://github.com/ExploreScientific/PMC-Eight-INDI-Driver-Source/releases/tag/PMC8-INDI-2.2.1-es1
```

## Important Packaging Note

Linux beta releases are now distributed as INDI-style Debian packages rather than loose executable bundles.

This is intentional. A raw `indi_pmc8_telescope` executable can fail on another system if it was linked against a different shared-library version, for example:

```text
libcfitsio.so.9: cannot open shared object file: No such file or directory
```

Debian packages solve this the same way the INDI project does: the packages are built on the target OS release, and Debian tooling records the correct runtime dependencies for that release. Ubuntu 22.04 and Ubuntu 24.04 use different CFITSIO runtime packages, so they need separate package builds.

Each Linux package set contains:

- `libindi-data_<version>_all.deb`
- `libindi1_<version>_<arch>.deb`
- `indi-bin_<version>_<arch>.deb`
- optional development/debug packages generated by the build
- `SHA256SUMS-...txt`
- `README-DEBIAN-...md`

The `indi-bin` package contains:

- `indiserver`
- INDI tools
- `indi_pmc8_telescope`
- the INDI driver XML data needed by KStars/Ekos

macOS artifacts remain ZIP bundles because macOS does not use Debian packages.

Legacy tar/zip bundles, when present, contain:

- `bin/indi_pmc8_telescope`
- `bin/indiserver`
- matching INDI shared libraries built from this source tree
- release notes
- an installer script

## Artifact Targets

- Linux PC/notebook Ubuntu 22.04 x86_64: Debian packages from the `ubuntu-22.04-x86_64-deb` artifact
- Linux PC/notebook Ubuntu 24.04 x86_64: Debian packages from the `ubuntu-24.04-x86_64-deb` artifact
- Raspberry Pi 64-bit Ubuntu 22.04 arm64: Debian packages from the `ubuntu-22.04-arm64-deb` artifact
- Raspberry Pi 64-bit Ubuntu 24.04 arm64: Debian packages from the `ubuntu-24.04-arm64-deb` artifact
- macOS Apple Silicon arm64: `pmc8-indi-beta-<version>-macos-arm64.zip`
- macOS Intel x86_64: `pmc8-indi-beta-<version>-macos-x86_64.zip`

The macOS target is split into Apple Silicon and Intel artifacts because INDI and Homebrew dependencies are architecture-specific.

## Download From The Formal Release

Go to the release page and download the artifact that matches the target system:

```text
https://github.com/ExploreScientific/PMC-Eight-INDI-Driver-Source/releases/tag/PMC8-INDI-2.2.1-es1
```

Linux PC/notebook or Raspberry Pi, Debian package install:

```bash
sudo apt update
sudo apt install ./libindi-data_*.deb ./libindi1_*.deb ./indi-bin_*.deb
```

Use the package set that matches the target OS release and CPU architecture. For example, an Ubuntu 24.04 Raspberry Pi 4 64-bit system should use the Ubuntu 24.04 arm64 package set, not the Ubuntu 22.04 arm64 package set.

Verify after installation:

```bash
which indi_pmc8_telescope
ldd $(which indi_pmc8_telescope)
indiserver -v indi_pmc8_telescope
```

macOS Apple Silicon:

```bash
unzip pmc8-indi-beta-PMC8-INDI-2.2.1-es1-macos-arm64.zip
cd pmc8-indi-beta-PMC8-INDI-2.2.1-es1-macos-arm64
sudo ./install.sh "$(brew --prefix)"
```

macOS Intel:

```bash
unzip pmc8-indi-beta-PMC8-INDI-2.2.1-es1-macos-x86_64.zip
cd pmc8-indi-beta-PMC8-INDI-2.2.1-es1-macos-x86_64
sudo ./install.sh "$(brew --prefix)"
```

Restart KStars/Ekos after installation.

## Create Artifacts With GitHub Actions

Run the workflow:

```text
Actions -> PMC-Eight Beta Artifacts -> Run workflow
```

Inputs:

```text
release_label: PMC8-INDI-2.2.1-es1
upload_to_release: true or false
```

When `upload_to_release` is `false`, artifacts are attached only to the workflow run.

When `upload_to_release` is `true`, artifacts are uploaded to the GitHub release whose tag matches `release_label`.

## Create Local Linux Debian Packages

From a Linux shell with INDI/Debian package build dependencies installed:

```bash
sudo apt update
sudo apt install build-essential cmake git pkg-config rsync \
  dpkg-dev devscripts debhelper cdbs fakeroot \
  libev-dev zlib1g-dev libcfitsio-dev libnova-dev libusb-1.0-0-dev \
  libcurl4-gnutls-dev libgsl-dev libjpeg-dev libfftw3-dev \
  libtheora-dev libogg-dev libudev-dev librtlsdr-dev liberfa-dev

cd PMC-Eight-INDI-Driver-Source
bash explorescientific/package_pmc8_debian_packages.sh
```

The output appears in:

```text
artifacts/
```

Install the generated runtime packages:

```bash
sudo apt install ./artifacts/libindi-data_*.deb ./artifacts/libindi1_*.deb ./artifacts/indi-bin_*.deb
```

## Restore Distribution INDI Packages

If a beta package needs to be removed, reinstall the distribution-provided INDI packages:

```bash
sudo apt update
sudo apt install --reinstall indi-bin libindi1 libindi-data
```

Depending on how KStars/INDI was originally installed, the user may need to reinstall from the INDI PPA or from their distribution repository.

## Build From Source On Any Linux System

For Linux systems that do not match one of the provided package artifacts, the most compatible path is to build on the target system:

```bash
sudo apt update
sudo apt install build-essential cmake git pkg-config \
  libev-dev zlib1g-dev libcfitsio-dev libnova-dev libusb-1.0-0-dev \
  libcurl4-gnutls-dev libgsl-dev libjpeg-dev libfftw3-dev

git clone https://github.com/ExploreScientific/PMC-Eight-INDI-Driver-Source.git
cd PMC-Eight-INDI-Driver-Source
mkdir -p build
cd build
cmake ..
make -j$(nproc) indi_pmc8_telescope
sudo make install
sudo ldconfig
```

Building on the target system links the driver against that system's own shared-library versions.
